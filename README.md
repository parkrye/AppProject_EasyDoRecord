# EasyDoRecord

인터넷 권한 없는 안드로이드 음성 녹음 · 편집 앱. 바로 녹음(앱 바로가기 · 빠른 설정 타일), 파형 보며 자르기 · 구간 삭제 · 분할, m4a 내보내기를 한 앱에서 하고, 녹음은 기기 밖으로 나가지 않음.

## 기능

| 영역 | 내용 |
|---|---|
| 녹음 | 일시정지 · 재개, 실시간 레벨 표시, 화면을 꺼도 계속 녹음(알림에서 일시정지 · 계속 · 정지), 품질 16 · 32 · 44.1 · 48kHz |
| 바로 녹음 | 앱 아이콘을 길게 눌러 "바로 녹음"(홈 화면에 고정 가능), 빠른 설정 타일 "바로 녹음"으로 즉시 시작 · 정지 |
| 목록 | 날짜 · 길이 · 크기, 이름 변경 · 삭제 · 공유 · 내보내기 |
| 재생 | 파형(누르거나 끌어서 이동), 탐색바, 5초 이동, 배속 0.5 ~ 2배, 선택 구간 재생 |
| 편집 | 자르기(선택 구간만 남김) · 구간 삭제(앞뒤 잇기) — 새 녹음 저장 또는 원본 덮어쓰기, 재생 위치에서 두 녹음으로 분할 |
| 내보내기 | m4a(AAC) · wav(원본), 원하는 위치에 저장 또는 다른 앱으로 공유 |

녹음은 무손실 WAV로 저장해 편집해도 음질이 떨어지지 않음. 내보낼 때 m4a로 변환.

## 설치

[Releases](../../releases)에서 `EasyDoRecord-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 처음 녹음할 때 마이크 · 알림 권한 요청. 알림은 녹음 중 표시와 일시정지 · 정지 버튼용
- 빠른 설정 타일은 알림창을 내려 편집(연필) 버튼에서 "바로 녹음"을 끌어다 추가
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 녹음 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `9c442d01b7f04ff1d8f85eac42c2fe2d3c68143dddc87054b3b7132e75265694`
  (`apksigner verify --print-certs EasyDoRecord-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 녹음은 앱 전용 저장소에만 저장. 앱 삭제 시 함께 삭제 (Android 클라우드 백업도 끔)
- 내보낸 파일은 사용자가 고른 위치 · 공유한 앱에만 전달. 보관할 녹음은 내보내기로 따로 저장
